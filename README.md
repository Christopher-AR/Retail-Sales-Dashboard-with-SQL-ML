# Retail Sales Dashboard with SQL & ML Prediction

##  Overview

This project presents an end-to-end **Retail Sales Analytics Dashboard** built using **SQL Server, Power BI, and Machine Learning (Python)**. It analyzes sales performance, customer behavior, product trends, and integrates a predictive model for forecasting future sales.


##  Objectives

* Analyze historical retail sales data
* Identify key revenue and profit drivers
* Detect loss-making areas
* Understand customer contribution patterns
* Build a machine learning model for sales prediction


##  Tech Stack

* **Data Processing:** SQL Server Management Studio (SSMS)
* **Visualization:** Microsoft Power BI
* **Data Transformation:** Power Query
* **Analysis:** Advanced DAX
* **Machine Learning:** Python (Jupyter Notebook)
* **Model:** Random Forest Regressor


##  Dataset

* Sample Superstore dataset
* Contains:

  * Order Date
  * Sales
  * Profit
  * Quantity
  * Discount
  * Category
  * Sub-Category
  * Region
  * Segment
  * Product Name
  * Customer Name


##  Dashboard Pages

### 1️ Sales Overview

* Total Sales, Orders, AOV KPIs
* Sales by Category, Region, and Product
* Monthly and yearly trends
* YoY Growth Analysis


### 2️ Profit Analysis

* Total Profit & Profit Margin
* Profit by Category and Sub-category
* Waterfall chart for profit contribution
* Loss-making sub-categories identification


### 3️ Customer Analysis

* Customer segmentation insights
* Top customers by sales
* Scatter plot (Sales vs Profit)
* **Insight:** Top 20% customers contribute 48% of revenue


### 4️ Product Analysis

* Sales and Profit by Category
* Sub-category performance
* Top-performing products
* Loss-making product identification


### 5️ ML Prediction Analysis

* Actual vs Predicted Sales trends
* Region & Category-level predictions



##  Machine Learning Model

### Model Used:

**Random Forest Regressor**

### Feature Engineering:

* Year, Month, DayOfWeek extraction
* One-hot encoding for categorical variables


##  Model Performance

* **R² Score:** 0.75
* **MAE (Mean Absolute Error):** 141.88
* **RMSE:** 308.89


## 💡 Key Insights

* Technology category drives the highest revenue
* Certain sub-categories generate consistent losses
* Customer base is **balanced** (low dependency risk)
* Sales trends show seasonal patterns
* ML model effectively captures sales behavior
